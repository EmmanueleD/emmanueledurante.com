# Emmanuele Durante — Visual identity

Use the same square navy tile (#13294B), solid white D (#FFFFFF) and horizontal cyan bar (#00A7E1) for the header and all app icons. Use cool white (#F5F5FA) for the page and light grey (#DCDFE4) for secondary surfaces. Set body copy in charcoal (#3E3E3E), headings in navy, and primary actions in cyan with navy labels. Brand red (#D93535) highlights secondary link underlines, navigation interactions, the current language and keyboard focus indicators. Deep crimson (#B00020) identifies form errors through message text and a left border.
